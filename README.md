# taqueria-app
# App de Pedidos para Taquería

## Descripción

Esta aplicación móvil permitirá a los clientes realizar pedidos de comida desde su teléfono de manera rápida y sencilla. Los usuarios podrán consultar el menú, agregar productos al carrito y realizar pedidos sin necesidad de acudir directamente al mostrador.

## Tecnología / Framework elegido

* React Native
* JavaScript
* Arquitectura MVC

desarrollado por Aaron Higuera

## Metodología de desarrollo seleccionada

Se utilizará la metodología Kanban para organizar las tareas del proyecto mediante un tablero con columnas como Pendiente, En proceso, En revisión y Terminado. Esto permitirá dar seguimiento al avance de cada actividad de manera sencilla.

## Objetivo del proyecto

Desarrollar una aplicación móvil que facilite la realización de pedidos en una taquería o restaurante, mejorando la experiencia del cliente y agilizando el proceso de atención.
